# 🎨 HIT VISUAL LUXURY

Генератор AI-артов через нейросеть Flux

## 🚀 Что умеет:
- Генерация артов по текстовому описанию
- 4 бесплатные генерации в день
- Загрузка своих фото (img2img)
- Разные стили: киберпанк, фэнтези, портреты, аниме

## 📱 Как использовать:
1. Перейди в приложение ВК
2. Введи описание или выбери стиль
3. Нажми "СОЗДАТЬ"
4. Скачай результат
